# PCM Industrial - Manutenção Preventiva V2

Sistema web estático para GitHub Pages. Não requer instalação.

## Recursos
- Dashboard executivo
- Cadastro técnico de planos
- Equipamentos/TAGs consolidados
- Programação automática por periodicidade
- Backlog de preventivas vencidas
- SS / Ordens de manutenção
- Checklist por plano
- Registro de execução e materiais
- Histórico e rastreabilidade
- Indicadores de aderência e horas preventivas
- Exportação JSON e CSV

## Publicação no GitHub Pages
Substitua os arquivos do repositório pelos arquivos desta pasta. O `index.html` deve permanecer na raiz do repositório.

## Armazenamento
Os dados são armazenados no `localStorage` do navegador. Para uso multiusuário, o passo seguinte é adicionar banco de dados online (Supabase/Firebase/API própria).
