# PCM Preventivas V6 — interface simples

Versão simplificada para GitHub Pages, inspirada em um mapa anual de 52 semanas.

## Tela principal
- Cronograma de 52 semanas com datas reais.
- Planos agrupados, mostrando quantidade de TAGs.
- Botão + para expandir as TAGs de cada plano.
- Filtro por plano/TAG, setor e responsável.
- Modos: Planejado, Realizado e Planejado + Realizado.
- Planejamento automático conforme última execução + periodicidade.
- Cores: azul = planejado, verde = realizado, vermelho = vencido, roxo = SS programada.

## Publicação
Substitua os arquivos do repositório GitHub Pages e faça Commit changes.
