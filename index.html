Segurança desta versão

O login desta V3 funciona no navegador para separar usuários e registrar autoria. Como o site está no GitHub Pages, ele não é um login corporativo seguro e os dados continuam locais. Para vários computadores compartilharem a mesma base e autenticação real, conecte um banco online (ex.: Supabase/Firebase).
